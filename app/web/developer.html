Product boundary

This API supports stewardship evidence only. It rejects detected identifiers, suppresses antibiogram cells below 30 isolates, persists no raw report text, and takes no clinical action.

  • Only a SHA-256 key digest is persisted.
  • The key expires automatically after seven days.
  • No credential is placed in browser storage.
  • Reading a report is the one call that invokes a model, capped at 25 per key per day.
  • Key creation is capped per address per day, so an open form cannot be farmed.
  • The public judge workflow needs no key at all.

  -d '{"subject_ref":"SUBJECT-101","acknowledge_deidentified":true,"document":"CULTURE AND SUSCEPTIBILITY REPORT\\nOrganism: Escherichia coli\\nSpecimen: Urine\\nCEFTRIAXONE <=1 S\\nCIPROFLOXACIN >2 R"}'

Run it here, with the key you made

This is the text that gets sent. Edit it, or paste a report of your own, then press send. Every value that comes back quotes the line it was read from, so you can check the answer against what you typed.
