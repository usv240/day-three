On day three of a hospital stay, someone should check whether the antibiotic is still right.

Day Three is a deployed agent fleet for the review limited teams can miss. It reads synthetic
scanned lab reports with measured Gemini output, builds a cumulative local antibiogram, registers
durable wakes, and returns at hour 48. Then it proves its boundary: a fabricated resistance number
is rejected, and the workflow stops for pharmacist review rather than changing an order.

Built on Cloud Run, Firestore, Cloud Scheduler, Cloud Trace, Gemini 3.5 Flash, Gemma 4, Gemini 3.1
Flash Image, and Veo 3.1 Fast.
